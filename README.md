# SANG Codex

Памятка для военнослужащих SANG (Majestic RP, сервер Orlando): поиск по законам и правилам, готовые ситуации с речью и порядком действий, конструктор задержания и тренажёр.

**Открыть:** https://sangcodex.online

> Неофициальный проект игроков. Не связан с администрацией Majestic RP. Тексты законов и правил — с форума проекта; при расхождениях действует форум. Дата сверки базы указана в шапке приложения.

## Возможности

- **Поиск** — своими словами («стреляли по нам», «посторонний на форте») или по номеру («ук 17.6», «пго 7.3»). Понимает сленг и опечатки.
- **Ситуации** — статьи с наказанием, готовая речь (копируется в чат по частям, клавиша Пробел), действия по шагам, подсказки «где можно залететь».
- **Разбор ситуации** — опиши случай целиком, приложение определит место, нарушителя и нарушение и перенесёт в конструктор.
- **Задержание** — конструктор: можно ли задерживать, какие статьи, речь и доклад по рации.
- **Учёба** — тесты по темам (ситуации, УК, АК, уставы, правила), тренировка и экзамен, колода без повторов и прогресс по темам.
- **🆕 Что нового** — какие статьи изменились при последних обновлениях законов.
- **🧠 ИИ-поиск** (по желанию) — поиск по смыслу; модель скачивается один раз и работает на устройстве без интернета.
- **🎤 Голосовой ввод** — в Chrome, Edge и Safari.

## Установка как приложения

- **ПК (Chrome / Edge):** значок установки в адресной строке → «Установить».
- **Android:** меню ⋮ → «Установить приложение» / «Добавить на главный экран».
- **iPhone (Safari):** «Поделиться» → «На экран „Домой“».

После первого открытия работает без интернета и обновляется само при следующем запуске с сетью.

## Состав

- `index.html` — приложение вместе со встроенной базой статей, пунктов и ситуаций
- `sw.js` — офлайн-режим и обновления
- `manifest.webmanifest`, `icons/` — установка как приложения
- `CNAME` — домен sangcodex.online (не удалять)
