# SANG Codex

Памятка для военнослужащих SANG (Majestic RP, сервер Orlando): поиск по законам, готовые ситуации с речью и порядком действий, конструктор задержания.

> Неофициальный проект игроков. Не связан с администрацией Majestic RP. Законы — по текстам с форума проекта; при расхождениях действует форум.

## Как пользоваться

**Телефон и ПК через браузер (рекомендуется):** откройте страницу проекта на GitHub Pages и установите как приложение:
- Android / Chrome / Edge: меню → «Установить приложение» / «Добавить на главный экран».
- iPhone / Safari: «Поделиться» → «На экран „Домой“».

После первого открытия работает без интернета и обновляется само.

**Windows-программа:** раздел **Releases** → скачать `SANG_Codex.exe`. Программа ничего не устанавливает, не работает с игрой и сетью — только окно с текстом законов. Исходный код — в папке `native/`, собирается автоматически GitHub Actions.

## Состав
- `index.html` — веб-приложение (PWA)
- `native/` — Windows-версия на C (Win32 API)
- `data/items.json` — база: статьи, пункты, ситуации
- `tools/build_db.py` — пересборка `native/db.bin` из базы

## Обновление законов
Изменить `data/items.json` → `python tools/build_db.py` → закоммитить → поставить новый тег `vX.Y`.
